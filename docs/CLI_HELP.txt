Exec/attach/forward/file copy require --write AND their separate --allow-* flag.
Helm lifecycle requires --write --allow-helm --allow-helm-write and a trusted
Helm 4.3.1 executable. Sources are local deterministic .tgz charts or exact
oci://HOST/repository/chart:TAG or @sha256:<64 lowercase hex> references.
Tags resolve once to a digest before review. Execution uses the sealed chart.
--helm-keyring requires valid OpenPGP provenance for acquired local/OCI charts;
stored-release test/rollback/uninstall do not reacquire or reverify chart provenance.
Without signature verification, digest integrity alone does not establish publisher identity.
--helm-sigstore-policy verifies exact chart bytes with Cosign 3.1.3 and explicit
bundle/public trust; it does not discover OCI manifest signatures or attestations.
Both selected signature policies must pass before review and again before writes.
Registry auth is an explicit private JSON file, never ambient Docker/Helm credentials.
Hooks require --allow-helm-hooks and complete review of their resources and lifecycle.
CRDs require --allow-helm-crds plus separate helm crds review before chart installation.
CRD schema creation is cluster-wide; only Namespaced custom-resource APIs are accepted.
Schemas remain on release uninstall. Explicit crds-upgrade/crds-delete review the
cluster-wide schema and instance impact; deletion requires DELETE CRDS namespace/release.
crds-migrate requires MIGRATE CRDS namespace/release approval. Only identical schemas
with None conversion are supported. Native rewrites retain historical storedVersions;
only a fresh successful StorageVersionMigration controller permits finalization.
Controller objects can continue after client cancellation and remain for inspection.
helm test runs stored test hooks with --allow-helm-hooks, without automatic logs.
Complete target review and namespace/release confirmation expire in 15 minutes.
Ctrl-C cancels; partial or unknown outcomes require inspection before retrying.
Multi-Pod logs capture at most 8 Pods/32 ordinary containers with one shared budget.
Membership stays fixed until an explicit new capture; replacements stop the stream.
Tool views require --allow-tools and RUN TOOL transfer approval (Unix only).
Trusted tools retain your OS-user filesystem/network access; no OS sandbox.
Output is sanitized/captured with a 15s/256KiB budget. No external interactive editor.
Native helper/tool execution is Unix-only; SDK sandbox preflight is macOS-only.
All writes and subresource operations require exact terminal confirmation.
Noninteractive exec/attach retain a 30s deadline. Interactive sessions use
Ctrl-] disconnect, stdin/resize, 1..3600s, 16MiB output/1MiB input. Output filters
unsafe terminal controls; remote full-screen apps remain unsupported.
Disconnect cannot guarantee remote termination. Follow defaults 1h; rolling
display 256KiB/2000 lines, 64MiB wire cap and per-second flood limits.
Overview snapshots have a 30s global budget; --follow watches Pods/Events in up to 4 contexts.

--allow-helm authorizes bounded Helm metadata reads. Lifecycle writes additionally
require --write, --allow-helm-write and an explicit trusted Helm executable.
Values are stored overrides with known fields redacted; custom keys may remain confidential.
Raw Helm storage, chart files/defaults, notes and manifests are never exported.
Merged logs include at most 16 ordinary containers and one shared output/session budget.

TLS verification is mandatory. General Secret reads, unreviewed auth helpers,
impersonation, generic patches and automatic AI requests remain disabled.
Registered views are opt-in; their OS containment remains a production gate.
All real clusters are labeled PRODUCTION; this is a target warning, not a
production certification. See docs/REMAINING_WORK.md for release gates.

Helm list: i install / u upgrade / t test / c chart CRDs / Enter or r history / Ctrl-D uninstall.
Helm history: r rollback selected revision. Charts use local .tgz or OCI :tag/@sha256:digest;
values files remain local. Hooks/CRDs stay disabled without their flags.
Helm review: read every line, then type the displayed confirmation and Enter.
CRD deletion requires DELETE CRDS namespace/release; migration requires
MIGRATE CRDS namespace/release; other actions use namespace/release.
Workload l/p opens merged current/previous logs; group a cannot widen source scope.

Copilot advice: local preview is available without setup. Inference requires a
pinned --copilot-policy, explicit stored gh account or private credential file,
and exact payload review. Existing gh authority can be broader than Copilot.
Demo never sends requests. Supported native macOS ARM64 builds use independently checked
process/network containment; other platforms fail closed. No automatic remediation.
See docs/COPILOT_INTEGRATION.md for trust, permissions and limitations.
