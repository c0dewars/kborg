KBorg 0.3 — Kubernetes operations, under your control

  kborg demo                     Offline sample cluster; no credentials
  kborg startup on|off           Persist startup animation preference

  kborg overview CONTEXT...       Snapshots 1..100; --follow watches up to 4 contexts
  kborg doctor                   Verify selected context and pod access
  kborg resources                Bounded API discovery (Secrets excluded)
  kborg pulses                   Resource health snapshot
  kborg workloads                Mixed workload snapshot

  kborg can u:NAME|g:NAME|s:NAME   Declared RBAC binding evidence

  kborg watch RESOURCE            Bounded live snapshots; --json emits JSONL

  kborg exec POD CONTAINER -- COMMAND [ARG...]   Reviewed exec; --interactive enables stdin/TTY

Options (put KBorg flags before exec's -- separator):
  --context NAME     --namespace NAME / -n NAME ("*" for all on reads)
  --kubeconfig FILE  --config FILE  --write (default READ ONLY)  --readonly
  --allow-tools      --tool ABS     --tool-arg ARG    --allow-extensions
  --allow-auth-helper --auth-helper-policy FILE
  --interactive     --session-seconds 1..3600    --log-seconds 1..86400
  --metrics-resources  --selector LABELS / -l LABELS (ui/list/watch/logs)
  --tail 1..2000      --since-seconds 1..86400   --head (logs only)
  --allow-helm       --helm-storage secret|configmap   --all-containers
  --allow-helm-write --helm-tool ABS --helm-values FILE --helm-timeout 1..900
  --allow-logs       --allow-exec   --allow-attach   --allow-forward
  --poll            --theme ID     --color=never    --json       --yaml
  --no-mouse        --follow          --previous     --no-splash      --demo       --help

Exec/attach/forward require --write AND their separate --allow-* flag.
Helm lifecycle requires --write --allow-helm --allow-helm-write and a trusted
Helm 4.3.1 executable. Local deterministic .tgz charts only; no hooks/plugins/CRDs.
Complete namespace-scoped review and namespace/release confirmation expire in 15 minutes.
Ctrl-C cancels; partial or unknown outcomes require inspection before retrying.
Multi-Pod logs capture at most 8 Pods/32 ordinary containers with one shared budget.
Membership stays fixed until an explicit new capture; replacements stop the stream.
Tool views require --allow-tools and RUN TOOL transfer approval (Unix only).
Trusted tools retain your OS-user filesystem/network access; no OS sandbox.
Output is sanitized/captured with a 15s/256KiB budget. No external interactive editor.
Native helper/tool execution is Unix-only; SDK sandbox preflight is macOS-only.
All writes and subresource operations require exact terminal confirmation.
Noninteractive exec/attach retain a 30s deadline. Interactive sessions use
Ctrl-] disconnect, stdin/resize, 1..3600s, 16MiB output/1MiB input. Output filters
unsafe terminal controls; remote full-screen apps remain unsupported.
Disconnect cannot guarantee remote termination. Follow defaults 1h; rolling
display 256KiB/2000 lines, 64MiB wire cap and per-second flood limits.
Overview snapshots have a 30s global budget; --follow owns up to 4 live watches.

Themes:
  theme list | use ID | reset | new ID --base BUILTIN | clone-current ID
  theme validate FILE | preview FILE | install FILE | replace FILE
  theme export ID --output FILE | remove ID
Replacement preserves an original .json.bak and refuses to overwrite it.

TUI navigation (k9s command grammar; full compatibility register in docs/K9S_COMPATIBILITY.md):
  :pods :po :dp :svc :nodes        Resource plural/singular/short names and GVRs
  :pod NAMESPACE /REGEX @CONTEXT   Namespace, filter and context arguments
  :pod 'app in (api,web)'          Server-side label selection
  :ctx [NAME]  :ns [NAME]          Context/namespace picker or direct switch
  :aliases / Ctrl-A               Resource and custom alias picker
  :pulses :workloads :xray RESOURCE  Health and relationships
  :can u:NAME|g:NAME|s:NAME         Declared RBAC evidence
  :dir PATH  :screendump           Local manifests / explicitly saved snapshots
  :helm [NAMESPACE] :history NAME   Native release metadata and stored revisions
  :logs LABELS                   Capture fixed multi-Pod logs in current namespace
  :themes :metrics :overview :actions  Additional KBorg views
  :q :quit / Ctrl-C               Quit

  j/k / arrows: rows   Enter: drill down   Esc: back   ?: help
  /REGEX: filter   /!REGEX: inverse   /-f TEXT: fuzzy   /-l LABELS: server selector
  Tab: command completion   Up/Down: command history   [ / ]: back/forward
  d: describe   y: redacted YAML   l: logs   p: previous logs   Ctrl-R: refresh
  Shift-N/A/S: sort name/age/status   C/M: CPU/memory sort on Pods and Nodes
  CPU/MEM refresh every 15s; - means unknown; ~ means UID absent, creation-time checked
  Table quantities are rounded to fit; d/m and CLI metrics retain exact measured values
  0: all namespaces   Space: mark
  Ctrl-S: explicitly save redacted resource snapshot   c: copy name (OSC52)
  e: reviewed container editor   Ctrl-D: reviewed deletion
  Pod s: shell   a: attach   F: prepare forwarding   f: show forward
  Workload s: scale (supported families)   r: restart (supported families)
  Helm: Enter/r history; history Enter/v stored values; d metadata; m resource identities; y metadata YAML
  Logs: a toggles all ordinary containers; Pod l honors default-container annotation
  Logs: 0 tail,1 head,2 1m,3 5m,4 15m,5 30m,6 1h; s autoscroll,w wrap,t timestamps,f fullscreen
  Themes: arrows preview, Enter saves, N creates from preview, Esc cancels
  Writes require --write and full exact target review; sessions need --allow-*.
  Unimplemented upstream operations show their limitation and never run another action.

--allow-helm authorizes bounded Helm metadata reads. Lifecycle writes additionally
require --write, --allow-helm-write and an explicit trusted Helm executable.
Values are stored overrides with known fields redacted; custom keys may remain confidential.
Raw Helm storage, chart files/defaults, notes and manifests are never exported.
Merged logs include at most 16 ordinary containers and one shared output/session budget.

TLS verification is mandatory. General Secret reads, unreviewed auth helpers,
impersonation, generic patches and automatic AI requests remain disabled.
Registered views are opt-in; their OS containment remains a production gate.
All real clusters are labeled PRODUCTION; this is a target warning, not a
production certification. See docs/REMAINING_WORK.md for release gates.

Helm list: i install / u upgrade / Enter or r history / Ctrl-D uninstall.
Helm history: r rollback selected revision. Forms require local chart/values paths.
Helm review: scroll through every line, then type namespace/release and Enter.
Workload l/p opens merged current/previous logs; group a cannot widen source scope.
