Options (put KBorg flags before exec's -- separator):
  --context NAME     --namespace NAME / -n NAME (all or "*" for every namespace)
  --kubeconfig FILE  --read-only (no changes)   --config FILE (operator restrictions)
  --interactive     --session-seconds 1..3600    --log-seconds 1..86400
  --session-escape KEY  Local key that ends a full-TTY session (default ctrl-])
  --metrics-resources  --selector LABELS / -l LABELS (ui/list/watch/logs)
  --tail 1..2000      --since-seconds 1..86400   --head (logs only)
  --helm-storage secret|configmap   --all-containers
  --helm-tool ABS --helm-values FILE --helm-timeout 1..900   (helm is found on PATH)
  --helm-registry-ca ABS --helm-registry-auth ABS  Explicit OCI TLS/auth files
  --helm-keyring ABS                           Require trusted OpenPGP chart provenance
  --helm-sigstore-policy ABS                   Require pinned Cosign chart-blob verification
  --scanner ABS                                Trivy or Grype (found on PATH when omitted)
  --copilot-policy ABS                         Copilot setup (copilot-policy.json in the config folder is used automatically)
  --node-shell-image IMG                       Image for node shell and debug containers
  --tool ABS --tool-arg ARG                    External view tool
  --allow-auth-helper --auth-helper-policy FILE   Reviewed helper mode (strict; refuses unreviewed helpers)
  --poll            --theme ID     --color=never    --json       --yaml
  --no-mouse        --follow          --previous     --no-splash      --demo       --help
  The old --write and --allow-* flags are still accepted; everything is already on.

Everything is enabled by default, like k9s: browsing, logs, edits, apply, scale,
restart, delete, exec/attach, port forwards, file copy, node shell, debug
containers, Helm, Secret reveal, scans, extensions and Copilot. Every change first
shows a review of exactly what will happen; y or Enter applies it, n or Esc cancels.
Use --read-only to browse without changes. A company can turn capabilities off,
force read-only or require typed confirmations with an operator --config file
("allow_exec": false, "profile": "read-only", "strict_confirmations": true).

Kubeconfig works as in kubectl: exec helpers (aws, gcloud, kubelogin, ...),
auth providers, impersonation, proxy-url and insecure-skip-tls-verify are honored.
Helm install/upgrade needs a context with a static token or client certificate,
because the helm binary receives those credentials.
Interactive exec/attach sessions are a full TTY like kubectl exec -it (vim, top,
less work): the remote program controls your terminal, unfiltered. Ctrl-] (or
--session-escape KEY) disconnects; resizes are forwarded; 1..3600s, 16MiB output/
8MiB input; terminal modes are reset on return. Follow defaults 1h; rolling
display 256KiB/2000 lines, 64MiB wire cap and per-second flood limits.

Themes:
  theme list | use ID | reset | new ID --base BUILTIN | clone-current ID
  theme validate FILE | preview FILE | install FILE | replace FILE
  theme export ID --output FILE | remove ID
Replacement preserves an original .json.bak and refuses to overwrite it.

  Helm: Enter/r history; history Enter/v stored values; d metadata; m resource identities; y metadata YAML
  Helm: i install; u upgrade; c chart CRDs; history r rollback; Ctrl-D uninstall
  Logs: a toggles all ordinary containers; Pod l honors default-container annotation
  Logs: 0 tail,1 head,2 1m,3 5m,4 15m,5 30m,6 1h; s autoscroll,w wrap,t timestamps,f fullscreen
  Themes: arrows preview, Enter saves, N creates from preview, Esc cancels
  Every change shows a review first; y/Enter applies, n/Esc cancels.
  Unimplemented upstream operations show their limitation and never run another action.

Values are stored overrides with known fields redacted; custom keys may remain confidential.
Merged logs include at most 16 ordinary containers and one shared output/session budget.

Helm list: i install / u upgrade / t test / c chart CRDs / Enter or r history / Ctrl-D uninstall.
Helm history: r rollback selected revision. Charts use local .tgz or OCI :tag/@sha256:digest;
values files remain local.
Helm review: y/Enter runs it after the review, n/Esc cancels.
CRD deletion requires DELETE CRDS namespace/release; migration requires
MIGRATE CRDS namespace/release; other actions use namespace/release.
Workload l/p opens merged current/previous logs; group a cannot widen source scope.

Copilot: :copilot advises on the selected resource and :ask answers questions about
the screen you are looking at. It needs a Copilot policy (copilot-policy.json in the
KBorg config folder, or --copilot-policy) and shows exactly what is sent first.
Supported on macOS ARM64 with process and network containment.
See docs/COPILOT_INTEGRATION.md.
