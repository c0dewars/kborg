Start with the repository [README](../README.md). Active user guides describe `release/next`; published tags and dated reports describe their own source revisions.

| Develop or extend the application | [Development guide](DEVELOPMENT_GUIDE.md) |
| Build, verify and publish | [Release process](RELEASE_PROCESS.md) |
| Plan later versions | [Roadmap](ROADMAP.md) |

Historical `*_ACCEPTANCE.md`, `RELEASE_REPORT*`, `PLATFORM_BUILDS*`, dated security reports and evidence files retain their original claims and limitations. They must not be relabeled as acceptance for a newer binary. The development guide includes earlier architecture sections; its current-contract notice and the active status/register take precedence where behavior changed.
