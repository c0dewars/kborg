# K8Borg 0.2

This prerelease adds bounded live LIST/WATCH updates and pod/container/node Metrics API views to the security-focused Rust terminal app. The default remains read-only. Watches reconnect with resource versions, clear revoked data, stop at cache limits, and can be replaced by explicit polling. Metrics include checked CPU/memory units, timestamp/window and clear optional-API errors. Existing guarded writes, themes and optional startup animation remain available.

Independent validation includes unit/contract tests, controlled protocol and quantity cases, real Docker Desktop lifecycle/RBAC tests, secure Metrics Server interoperability on an owned Kubernetes 1.34.11 cluster, Windows PTY checks, WSL/Linux execution and bounded performance measurements. See WATCH_METRICS_IMPLEMENTATION.md and the separate evidence reports for exact source hashes, scope and limitations. Native artifacts count as verified only when their corresponding build and checksum checks succeed.

Archives include exact source/target metadata, dependency inventory, user documentation and theme notices. Binaries are unsigned; macOS packages are not notarized. Production security and operational gates, editing, simultaneous multi-context workflows and isolated Copilot diagnosis remain incomplete. This release does not claim production certification, exhaustive terminal compatibility or 100 independent-cluster capacity. Modern visual redesign still follows feature completion.
